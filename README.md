# [FairScope] (v2.6 Enterprise)
### Intelligent Freelance Contract & Client Boundary Protection Platform

[FairScope] is a production-grade, high-craft SaaS application designed with a **Modern Obsidian & Electric Violet Legal-Fintech aesthetic** ("Linear meets Stripe") for freelancers, agencies, and independent consultants. It cross-references incoming client messages against signed contracts and statements of work (SOWs), flags hidden scope creep, calculates unbilled hours and financial risk, and drafts diplomatic, tone-calibrated client responses and change orders in seconds.

---

## 🚀 Key Features

### 1. Workspace Analyzer (Split-Screen Audit Tool)
- **Scenario Quick-Load Engine:** 3 one-click realistic presets:
  1. *E-Commerce Website Build (High Scope Creep — Razorpay UPI + Wholesale B2B Page)*
  2. *Brand Identity & Logo Package (Partial Creep — Extra 3D Mockups & Urgent Rush Sprint)*
  3. *Monthly Social Media Retainer (In-Scope Request — Safe to Proceed)*
- **Contract & SOW Parser:** Character counter, file reader button for `.txt` and `.md` contracts, and clause boundary analysis.
- **Commercial Calibration:** Dynamic hourly rate and 3-way Client Sensitivity selector (`New Client`, `Long-Term Partner`, `Repeat Scope-Creeper`).
- **Omni-Channel Message Composer:** Channel switcher (`WhatsApp`, `Email`, `Slack`) with keyboard shortcut `Ctrl + Enter` to audit.
- **Executive Verdict Banner:** Color-coded status badge (`OUT-OF-SCOPE ALERT`, `PARTIAL SCOPE CREEP`, `IN-SCOPE — SAFE TO PROCEED`) with an animated radial **Scope Creep Risk Gauge (0% – 100%)**.
- **Financial Impact Strip:** Estimated extra effort hours, unbilled revenue at risk, and an **inline-editable Change-Order Quote** with INR (`₹`) support.
- **Itemized Breakdown:** Detailed cards identifying client ask, status tag, exact contract clause citations with quote icons, effort, and cost.
- **Diplomatic Response Studio:** 3 tone-calibrated tabs (*Collaborative & Warm*, *Firm Professional Boundary*, *Paid Change-Order Upsell*) with 1-click **Copy**, **Open in WhatsApp Web**, and **Open in Email**.
- **Formal Change-Order Addendum Generator:** Ready-to-sign formal Exhibit B addendum with signature blocks, "Copy Plain Text", and clean **"Download PDF / Print"** (`window.print()`).
- **Automation Action Bar:** "Save & Sync to Revenue Log" with celebratory confetti and real-time **Make.com / Zapier / Google Sheets** webhook dispatch.

### 2. Protected Revenue Log & Analytics Dashboard
- **Executive Metrics:** Total Audits Run, Scope Traps Caught, Total Hours Saved, and Total Protected Revenue.
- **Visual Ratio Bar:** CSS/SVG stacked distribution comparing compliant milestone work vs. protected upsell revenue.
- **Audit History Table:** Pre-seeded with realistic audits, real-time search, verdict filtering, channel filtering, "Open in Analyzer" drill-down, and **Export to CSV**.

### 3. Reliability & Gemini API Engine
- Direct REST integration with Google Gemini:
  - Primary Model: `gemini-4-hydrogen`
  - Automatic Fallback Model: `gemini-3.8-flash`
  - Strict JSON Schema validation guaranteeing stable UI output.
- **Deterministic Demo Engine:** Instant, context-aware simulated AI analysis with 1.2s multi-step progress when running in Demo Mode or without an API key.
- **100% Client-Side Privacy:** Local storage persistence for keys, rates, and audit logs.

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rkp5555/Fairscope.git
   cd Fairscope
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
